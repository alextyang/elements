# Original cloud basis assets

These raw, headerless RGBA8 textures are generated by
`scripts/generate-cloud-noise-assets.mjs` and are original to Elements. They
contain periodic multi-frequency basis fields, not copied shader-pack data.

- `cloud-base-rgba8-128.bin`: 128 × 128 × 128 RGBA volume (8 MiB)
- `cloud-base-average-rgba8-mips-64.bin`: packed 64³…1³ RGBA average mip tail
- `cloud-detail-rgba8-64.bin`: 64 × 64 × 64 RGBA volume (1 MiB)
- `cloud-detail-average-rgba8-mips-32.bin`: packed 32³…1³ RGBA average mip tail
- `cloud-weather-rgba8-256.bin`: 256 × 256 RGBA map (256 KiB)

Regenerate them with `npm run sky:noise`. Runtime validates each exact byte
length before upload. The average-filtered tails are generated offline and
uploaded as complete trilinear 3-D mip pyramids; projected pixel footprint
selects LOD analytically inside ray loops, where implicit derivatives are not
legal. Conservative maximum mips remain separate because empty-space skipping
and band-limited appearance require different filters. If a required asset is
unavailable, initialization enters the proven legacy no-cloud sky rather than
building millions of filter taps on the UI thread.

## Authoritative formation-volume atlas

`cloud-macro-atlas-v2.json` describes 34 deterministic 48³ canonical formation
volumes packed along Z in `cloud-macro-atlas-v2-rgba8-48.bin`. One empty guard
slice borders each volume. Its channels are macro density (R), billowy-to-wispy
detail type (G), liquid-to-ice fraction (B), and conservative signed distance
(A). The companion `cloud-macro-majorants-v2-r8-6.bin` stores one conservative
potential-density value per 8³ brick, including a one-voxel sampling halo. It
bounds both occupied macro density and every permitted procedural exterior
displacement plus the signed-distance cell-interpolation halo, so traversal can
never skip a cauliflower lobe, ragged sheet edge, ice fibre, or fallstreak only
because the coarse R channel is zero.

Version 2 includes a separately checksummed exterior-boundary contract. Every
formation declares only the physical detail classes it permits, their maximum
axis-scaled outward reach and density ceiling, and any protected condensation
base. The exact class-selection, signed-distance normal, displacement,
majorant, and lighting/view composition order is embedded in the manifest.
Hard protected cores are limited to connected lower liquid updrafts in deep
convection; fair-weather, decaying, and glaciated forms retain freely erodible
boundaries. Version 1 remains in the asset directory as the unchanged legacy
fallback.

The manifest also stores occupied-column density integrals along crosswind,
vertical, and downwind axes. The renderer uses the vertical cloudy-column mean
to turn normalized atlas density into the physical optical depth implied by
each system's liquid/ice water path and local spectral mass extinction.

The atlas covers the complete requested formation slice: the Cumulus and
Cumulonimbus lifecycle; five Cirrus species; a shared Cirrostratus veil;
Cirrocumulus and Altocumulus cellular, castellated, floccus, and wave forms;
Altocumulus and Stratocumulus volutus; Altostratus and precipitating
Nimbostratus sheets; Stratocumulus cellular/wave forms; Stratus nebulosus and
fractus; and Cumulus fractus. Cirrostratus fibratus and nebulosus intentionally
share the same macro veil—runtime fibre concentration differentiates them.

These are formation templates rather than camera-space silhouettes:

- Cirrus uses sheared, sedimenting ice trajectories with attached generators.
- Cellular families use deterministic Poisson owners, not jittered grids.
- Layer clouds use finite, undulating inversion or frontal volumes with
  condensate-defined irregular boundaries; Nimbostratus includes attached
  precipitation shafts.
- Lenticularis uses stationary finite wave lenses, while volutus uses one
  tapered, gently curved horizontal-roll tube.
- Fractus uses intentionally disconnected, turbulence-eroded physical shreds.

The compact 48³ resolution keeps the dense RGBA atlas at 14.06 MiB; fine
boundary structure remains a runtime procedural concern. The loader repacks
192-byte RGBA source rows to WebGPU's 256-byte upload alignment without changing
the stored asset. Generate with `npm run sky:cloud-atlas`; runtime loading,
checksum verification, classification lookup, sampling transforms, aligned
WebGPU upload, and cleanup are in
`components/backgrounds/sky/cloud-volume-atlas.ts`.

The original deterministic generator follows the voxel-authoring and
compressed-distance-field direction documented by Guerrilla's
[Nubis³](https://www.guerrilla-games.com/read/nubis-cubed), while using no
third-party shader or volume data. Its explicit brick majorants preserve a path
to sparse-brick traversal if later lifecycle sampling outgrows the dense atlas.

### High-ice source atlas

`cloud-high-ice-sources-v1-rgba8-96.bin` is the guarded `highIceSourceAtlas`
runtime representation. It is one linearly filtered `rgba8unorm` 3-D texture
at group 0, binding 32. Eleven non-analytic high-ice volumes are packed as
96³ source tiles in a 196 × 196 × 294 XYZ-tiled atlas. Each tile has one clear
guard voxel on every face; unused tail tiles are clear as well, so linear
filtering cannot bleed between source volumes. The payload is 45,177,216 bytes
(43.08 MiB). Keeping the source as one sampled binding preserves the shared
fragment pipeline's guaranteed 16-sampled-texture constraint.

The channels retain the conditioned fine realization and its coarse moments:

- `R`: exact block-mass-conditioned fine density (`sample / 255`), with each
  2³ child block summing to the authoritative coarse macro-R mass;
- `G`: coarse support coverage, replicated over the corresponding 2³ children;
- `B`: conditioned `E[rho²]` for that 2³ block, replicated over its children;
- `A`: conditioned fine support (`occupied = sample >= 0.5`, encoded as 0/255).

Unsupported coarse parents and all guards are zero in all four channels. The
manifest-derived source scale/offset pair is appended to `CloudMacroBinding`
as the final two records of its seven-`vec4` (stride-7) owner ABI. Its explicit
availability sentinel is zero for analytic or non-high-ice owners.

Camera and directional Sun/Moon paths use one owner-space footprint `q`, not
independent screen-space noise. With lateral/axial footprint radii and source
voxel sizes, `q = max(2 r_lateral / Delta_lateral, 2 r_depth /
Delta_axial)`. `q <= 1` resolves the fine source; `q >= 2` returns to
authoritative macro R plus the packed `G/B` moments, with a continuous log₂(q)
transition. Macro R, SDF, and conservative majorants remain authoritative for
support, culling, and geometry.

For source-backed Ci/Cc/Cs owners, the fine realization replaces the former
procedural high-ice residual. The expected-Beer closure consumes the resolved
mean, conditioned second moment, support, source-cell correlation, and physical
path/footprint once. Analytic Ci fibratus remains a specialized tangent-relative
subvoxel path and is not routed through this generic source representation.

`highIceMomentSidecar` (`cloud-high-ice-moments-v1-rg8-48.bin`) remains an
independently checked and useful offline provenance artifact: its coarse
coverage/moment reductions qualify and regenerate the source atlas. It is not
uploaded or sampled at runtime and is not a second Beer closure. Resident P1
light-volume storage keeps arithmetic extinction and scattering, so expected
Beer is never folded into that shared direct field twice.
